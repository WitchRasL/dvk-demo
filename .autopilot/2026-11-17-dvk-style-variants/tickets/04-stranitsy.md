## Что должно заработать

Посетитель любого варианта проходит весь путь на реальных данных: главное меню → направление → раздел/категория → товар → «Добавить в запрос КП» → страница «Запрос КП» → квиз (4 шага) → экран успеха (демо). Работают каталог с фильтрами в URL, поиском, сортировкой, пагинацией и быстрым просмотром; страница товара; решение для аптек с сериями (шаблон для любой отрасли); проекты и кейс; о компании и производстве; контакты двух городов с реквизитами; политика ПД (заглушка). Страницы собраны на `ui` варианта (`useVariant().ui`, откат на `core/ui/base`) и токенах, корень каждой — `<main className="page page-<name>">`, чтобы варианты могли перекрыть стили; анимация появления — через `ui.Reveal`.

## Из брифа, дословно

> «Навигация по ~4 000 позиций идёт удобным путём: направление → отрасль → категория → товар → «Добавить в запрос КП».»
> «интуитивно понятная, удобная логика расположения разделов, продуктов и т.п., чтобы в последующем разместить продукты с текущего сайта dvk-style.ru»
> «Каталог — направления → категории. Фильтры: направление, отрасль, категория, материал, подсветка, поиск. Фильтры синхронизируются с URL. Сортировка и быстрый просмотр товара.»
> «Карточка товара — галерея, характеристики, кнопка «Добавить в запрос КП», похожие товары, блок «Как мы работаем».»
> «Решение для отрасли — на примере «Аптеки» с сериями; это шаблон для остальных отраслей.»
> «Проекты — галерея и страница кейса.»
> «О компании / Производство — полный цикл, клиенты, благодарственные письма, сертификаты (если они есть на сайте).»
> «Контакты — Санкт-Петербург и Москва, переключатель города в шапке.»
> «Форма заявки / квиз подбора. 3–4 шага: направление → объект → сроки → контакты.» · «Маска телефона +7, согласие на обработку ПД (152-ФЗ), прикрепление плана помещения (необязательно).»
> «Главное действие — заявка на бесплатный подбор, замер или расчёт проекта. Второе — звонок.»
> «Адаптив: 360 / 768 / 1024 / 1440. На мобильном карточки идут горизонтальным scroll-snap.» · «семантичная разметка, стили фокуса, alt-тексты из названий товаров»

## Критерии приёмки

- [ ] `useNav()` отдаёт меню: Каталог (направления → разделы с числом товаров), Решения (отрасли), Проекты, Производство, Контакты; с главной до любого товара ≤3 кликов
- [ ] Каталог: `/catalog`, `/catalog/:direction`, `/:section`, `/:category`; фильтры (направление, отрасль, категория, материал, подсветка, поиск), сортировка, пагинация — всё в URL и восстанавливается по ссылке; хлебные крошки; `data-direction` на странице
- [ ] Пустой результат: что не найдено, «Сбросить фильтры», «Подберём сами — оставьте заявку» → квиз
- [ ] Быстрый просмотр товара из каталога: фото, главные характеристики, «В запрос КП», ссылка на страницу товара; закрывается Esc и кликом вне, фокус возвращается
- [ ] Товар: галерея (`srcset`, `loading="lazy"` кроме первого фото), характеристики, цена или «по запросу», «Добавить в запрос КП» (меняется на «В запросе · изменить количество»), похожие товары, «Как мы работаем» (5 шагов из `company.json`), ссылка на товар на dvk-style.ru, хлебные крошки
- [ ] Решение для отрасли `/solutions/pharmacy`: серии аптек, типы оборудования, товары отрасли, заявка; та же страница работает для любой отрасли из `categories.json`
- [ ] Проекты: галерея с фильтром по направлению; кейс: фото, объект, город, что сделано — только данные
- [ ] О компании: полный цикл, услуги (брендирование, госзаказ, ТЗ к тендерам), клиенты, благодарственные письма; сертификаты — только если есть в данных
- [ ] Контакты: обе площадки (адрес, `tel:`, `mailto:`, режим работы если есть, «Открыть в Яндекс Картах»), выбранный город первым, реквизиты, кнопка заявки
- [ ] Запрос КП: список с количеством и удалением, пустое состояние со ссылками в каталог и на квиз; квиз — 4 шага, черновик восстанавливается, ошибки у полей по-русски, маска +7, файл (необязательно), согласие 152-ФЗ со ссылкой на `/privacy`, обещание «Бесплатный подбор, ответ в течение 2 часов»; двойная отправка заблокирована; успех в демо-режиме с пометкой «Демо: заявка не отправлена»; ошибка сервиса — сообщение, данные на месте, телефон города
- [ ] Все страницы без горизонтального скролла на 360/768/1024/1440; на мобильном ряды карточек — горизонтальный scroll-snap; видимый фокус; alt фото = название товара; страницы ленивые
- [ ] На всех страницах есть главное действие (заявка) и телефон выбранного города
