## Критерии приёмки — слова приёмщика, дословно

- [ ] **P1.** «Без `alt`: 3 из 8 картинок на карточке товара RAL, 2 из 7 — «Чертёж» (какие именно — не разбирал).» Проверялось на странице товара (`/#/ral/product/<slug>`, `/#/blueprint/product/<slug>`). Условие: у каждой содержательной картинки на странице товара во всех трёх вариантах есть непустой `alt` из названия товара (у фото галереи — название и номер фото; у похожих товаров — их названия); картинка, которая ничего не сообщает (повтор фото под чертежом, фон), помечена как декоративная (`alt=""` + `aria-hidden="true"`) — и таких на странице нет среди фото товара. Тест на это стоит на странице товара, а не на внутренностях варианта.
- [ ] **P2.** ««Палитра RAL», 390 px: первая карточка раздела ~0,7 с после появления не принимает нажатие (автонажатие через 0,4 с не сработало, через 1,2 с — сработало).» Условие: карточка раздела в каталоге «Палитры RAL» на 390 px принимает нажатие сразу, как только видна (анимация появления не блокирует указатель и не держит элемент под слоем).

Общее:

- [ ] Больше ничего не меняется: вид и поведение страниц те же. `npm run check` зелёный, тестов не меньше 472.
