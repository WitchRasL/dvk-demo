# ДВК Стиль — концепт редизайна dvk-style.ru

Рабочий прототип нового сайта «ДВК Стиль» в трёх вариантах с переключением:
«Шоурум», «Палитра RAL», «Чертёж». Каталог, данные, запрос КП и квиз общие;
у каждого варианта своя главная, свой визуальный мир и своя «фишка».

Концепт закрыт от поисковиков: `noindex, nofollow` в `index.html`, `Disallow: /` в `public/robots.txt`,
в футере каждого варианта — «Концепт редизайна dvk-style.ru».

## Команды

Нужны Node.js 22+ и npm.

| Команда | Что делает |
|---|---|
| `npm install` | установить зависимости |
| `npm run dev` | локальный сервер: http://localhost:5173/dvk-style-redesign/ |
| `npm run build` | сборка в `dist/` |
| `npm run preview` | открыть сборку: http://localhost:4173/dvk-style-redesign/ |
| `npm test` | тесты (Vitest) |
| `npm run check` | тесты + сборка — одна команда проверки |
| `npm run fetch-images` | скачать фото с dvk-style.ru и сконвертировать в WebP 800/1600 |
| `npm run shot -- <url> <file.png> [--width 390] [--full]` | скриншот через установленный Chrome |

Для `npm run shot` нужен Google Chrome; другой путь к браузеру — переменная `CHROME_PATH`.

## Как переключать варианты

- Плавающий переключатель в левом нижнем углу любой страницы: «1 Шоурум», «2 Палитра RAL», «3 Чертёж».
- Клавиши `1`, `2`, `3` (когда курсор не в поле ввода).
- «О вариантах» — панель с описанием всех трёх рядом: метафора, палитра и шрифты, фишка, направления,
  схема главной. На телефоне — кнопка «1/3», панель раскрывается снизу.
- Вариант — первый сегмент адреса: `/#/ral/catalog/metal?q=шкаф` → `/#/blueprint/catalog/metal?q=шкаф`.
  Переключение оставляет ту же страницу и фильтры.
- `/` открывает последний выбранный вариант, по умолчанию «Шоурум».

## Hero-ролик

В hero каждого варианта — скролл-видео. Пока ролика нет, работает заглушка: фото проекта ДВК
с движением камеры по скроллу. Готовый ролик подставляется одним файлом:
`public/media/<вариант>/hero.mp4` (и по желанию `hero-mobile.mp4`), правка кода не нужна.
Требования к файлу и команда `ffmpeg` — в [docs/hero-video/README.md](docs/hero-video/README.md);
раскадровка и промпт для каждого варианта — `docs/hero-video/<вариант>.md`.

## Отправка заявок

Без настройки квиз работает в демо-режиме: заявка не уходит, на экране честная пометка.
Чтобы заявки отправлялись, создайте `.env` по образцу `.env.example` и укажите адрес формы
Formspree или Web3Forms в `VITE_FORM_ENDPOINT`, затем пересоберите сайт. Ключи сервисов в код не кладутся.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий `dvk-style-redesign` и отправьте в него проект
   (вместе с `public/images/` и `package-lock.json`).
2. Включите Pages с источником GitHub Actions: *Settings → Pages → Source: GitHub Actions*
   (или `gh api -X POST repos/<owner>/dvk-style-redesign/pages -f build_type=workflow`).
3. Каждый push в `main` запускает `.github/workflows/deploy.yml`: `npm ci` → `npm run build` → публикация `dist/`.
4. Сайт: `https://<owner>.github.io/dvk-style-redesign/`. Адрес задан в `vite.config.js` (`base`);
   при другом имени репозитория поменяйте `base`.

Маршрутизация на `HashRouter`, поэтому прямые ссылки вида `/#/showroom/product/<slug>` работают
после обновления страницы и на Pages.

## Структура

- `src/core/` — общее ядро: реестр вариантов, оболочка и переключатель, каталог, запрос КП, город, квиз,
  скролл-видео, страницы.
- `src/variants/<вариант>/` — вариант: токены, шрифты, шапка, футер, главная, карточка товара.
- `src/data/*.json` — данные компании и каталога (только проверенные факты; неизвестное — `[уточнить]`).
- `src/components/ui/` — место для компонентов 21st.dev (см. README там).
- `src/lib/` — `cn()`, `asset()` (пути от `import.meta.env.BASE_URL`), `srcSet()`.
