# Один SPA, вариант — первый сегмент пути

## Контекст
Заказчик хочет сравнивать три варианта сайта один к одному и остаться на той же странице при переключении (R02, R70i). Публикация — на GitHub Pages.

## Решение
Прототип — одно приложение на React Router с HashRouter. Вариант — первый сегмент пути: `/#/<variant>/…`. Переключение меняет только этот сегмент и сохраняет остаток пути и query. Неизвестный id ведёт на `showroom` с тем же остатком; последний выбранный вариант хранится в `localStorage['dvk-variant']`.

## Почему
- Сравнение страницы в трёх вариантах — это смена одного сегмента; данные и логика не дублируются.
- HashRouter не требует настройки сервера на Pages: прямая ссылка на товар работает после обновления страницы (R42).
- Отвергнуто: три отдельных сайта. Переключение «на той же странице» потребовало бы сопоставлять адреса между сайтами, а каталог, КП и квиз пришлось бы держать в трёх копиях.

## Последствия
- Адреса содержат `#`; для финального сайта придётся менять тип роутера и перенастраивать ссылки.
- Любой новый маршрут обязан жить под `/:variant/…`, иначе переключатель его не сохранит.
- Все три варианта делят одну сборку и один набор маршрутов — вариант не может иметь страницу, которой нет у других, без правки ядра.
