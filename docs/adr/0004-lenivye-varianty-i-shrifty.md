# Варианты и их шрифты загружаются лениво

## Контекст
Цель Lighthouse mobile: Performance не ниже 85 (R59). У каждого варианта свои шрифты с кириллицей, у V1, V2 и V3 они разные.

## Решение
Модуль варианта подгружается через `import()` по id из реестра. Шрифты (`@fontsource`, подмножества cyrillic и latin) и CSS варианта импортируются в его собственном модуле. Страницы ядра ленивые (`React.lazy`). Метаданные варианта (`meta.js`) лёгкие и импортируются статически, чтобы панель переключателя показывала все три варианта, не загружая их.

## Почему
- Отвергнуто: подключить всё в общей сборке. Посетитель V1 скачал бы шрифты и код V2 и V3 и потерял бы в скорости.
- Отвергнуто: подгружать метаданные лениво вместе с модулем. Панель показывала бы описания трёх вариантов только после загрузки всех трёх.

## Последствия
- `VariantProvider` приостанавливается через `use()`: над деревом нужен `Suspense`, тесты рендерят через `await act(async …)`.
- При переключении варианта появляется пауза на загрузку его модуля и шрифтов.
- Основной чанк (около 147 КБ gz, из них motion около 46 КБ) — запас под Performance; если не хватит, запасной ход — `LazyMotion`.
