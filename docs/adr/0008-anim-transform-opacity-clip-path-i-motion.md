# Анимируются только transform, opacity и clip-path; библиотека — Motion

## Контекст
Сайт насыщен scroll-анимациями и должен укладываться в Performance не ниже 85 на мобильных (R57, R59). Брифом заданы Motion (`motion/react`); GSAP и Lenis допускаются только если без них не получается «фишка» (R40).

## Решение
Анимируются только `transform`, `opacity` и `clip-path`; easing и длительности берутся из токенов варианта. Любое движение имеет вариант для `prefers-reduced-motion`. Библиотека — Motion; GSAP и Lenis не подключены. Линии «Чертежа» вычерчиваются через шторку clip-path, а не через `stroke-dashoffset`. Тест сторожа в `src/variants/conventions.test.js` следит, что в CSS вариантов переходы идут только по этим свойствам.

## Почему
- Три свойства не вызывают перерасчёта раскладки; остальные дают рывки на слабых телефонах.
- Отвергнуто: `stroke-dashoffset` для линий чертежа, это нарушало бы правило.
- Отвергнуто: GSAP и Lenis. Все три фишки получились на Motion и CSS, а лишняя зависимость ударила бы по размеру бандла.
- Единое правило отключения движения (одно CSS-правило ядра) вместо своих проверок в каждом варианте: под `reduce` варианты задают только конечные состояния.

## Последствия
- Эффекты, которым нужны другие свойства (размытие, смена размеров, анимация цвета), недоступны; их приходится имитировать слоями с opacity.
- Новые зависимости (кроме списка из T01) запрещены без отдельного согласования.
- Кинетическая типографика и «заливка» полей RAL реализуются через clip-path и transform, что ограничивает дизайн.
