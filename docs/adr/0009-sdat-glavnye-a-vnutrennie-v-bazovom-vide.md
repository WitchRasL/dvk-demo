# Сдаём главные трёх вариантов, внутренние страницы — в базовом виде

## Контекст
Заказчик выбирает вариант по главной. Пользователь (G03): «Полностью пока сайт не создавай, нужны главные страницы»; полный сайт с каталогом из Битрикс — позже. Внутренние страницы уже собраны ядром (T04).

## Решение
Для каждого из трёх вариантов готовы главная (hero со скролл-видео, 6–8 экранов, фишка, шапка, футер). Внутренние страницы остаются рабочими, но работают в базовом виде на токенах варианта. Оформление внутренних страниц в языке варианта (R03.1) переносится на этап полного сайта, после выбора варианта заказчиком. Файлы `pages.css` вариантов — заготовки, не развиваются.

## Почему
- Отвергнуто: полное оформление трёх вариантов. Две трети работы пропали бы после выбора заказчика.
- Отвергнуто: убрать внутренние страницы совсем. Переключатель «на той же странице» и путь каталог → товар → КП нужно показывать.
- Токены (ADR 0003) дают внутренним страницам различие бесплатно.

## Последствия
- Различие вариантов внутри сайта слабее, чем на главной; заказчик может решить, что варианты схожи, и это надо проговорить при показе.
- После выбора варианта потребуется отдельный этап: стили внутренних страниц, анимации списков и шагов квиза.
- Не развивать `pages.css` невыбранных вариантов: любая работа там потеряется.
