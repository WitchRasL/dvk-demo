# Откуда взят контент

Все данные прототипа — с dvk-style.ru, собраны 18.11.2026. Неизвестное не додумано: в данных стоит `null` или `[уточнить]`, список — в [todo-utochnit.md](todo-utochnit.md).

## Как пересобрать

```
node scripts/collect/collect.mjs   # страницы → src/data/*.json, scripts/collect/image-jobs.json, docs/todo-utochnit.md
npm run fetch-images               # фото → public/images/…/<n>-1600.webp и <n>-800.webp + manifest.json
```

Оба скрипта ведут себя вежливо:

- соблюдают `robots.txt` (разбор — `scripts/collect/robots.mjs`);
- делают паузу 0,5–1 с между любыми запросами;
- кэшируют HTML и оригиналы фото в `scripts/collect/.cache/` (этот путь в `.gitignore`).

Повторный запуск идёт из кэша и уже скачанное не качает.

Закрытые в `robots.txt` страницы не открывались: `/company/partners_and_clients/`, `/company/konfid.php`, адреса с `?` (пагинация, фильтры), поиск.

## Правило честности в коде

Тексты о компании написаны коротко, но каждый проверяется. Функция `verify()` в `collect.mjs` ищет на исходной странице дословные фрагменты: адреса, телефоны, «в течение 2х часов», «Ижорские заводы», «более 9 лет» и т. п. Если фрагмента нет, сбор падает. Описания отраслей и услуги «Брендирование» — дословные предложения со страниц каталога (`siteSentence()`).

## Что редакторское, а не с сайта

- **Чистые названия категорий** (`scripts/collect/catalog-map.mjs`): регистр, «Островки для …» вместо голого «БИЖУТЕРИЯ» внутри раздела островков, без хвостов поставщиков. Старые названия всех уровней (192 штуки) лежат в `categories.json → aliases` с адресом на id нового узла. Значение алиаса — id категории или раздела.
- **Дубли и пустые пункты.** «Промышленная мебель» и её пункты с кодом на «1» слиты с «Металлической мебелью». Пункты меню без числа товаров («Мебель для фитнеса», «Стеллажи фронтальные», серия «Грин») стали только алиасами.
- **Сводка направления** (`summary`) — перечень его разделов.
- **Отрасли**: группировка категорий и названия («Аптеки», «Склады и цеха» …). Текст описания — с сайта.
- **Серии аптек**: названия переведены из капса («АМПИР» → «Ампир», «ORANGE» → «Orange»), исходные — в алиасах.
- **Товары**: какие взять (`picks.mjs`), категория в новом дереве, отрасли, `kind`. Остальные поля выведены из характеристик сайта:
  - `dimensions` — из «Размеры ВхШхГ / ДхШхВ / ВШГ, мм», если там ровно три числа. Буквы читаются как на сайте: В — высота, Ш — ширина, Г — глубина, Д — длина (идёт в `w`, тогда Ш — в `d`). Иначе `null`, строка остаётся в `specs`.
  - `materials` — по словам в «Материалах», столешнице или корпусе; кромка не считается. Если слов нет — по названию товара («бетонная» → `concrete`), для разделов металлической мебели — `metal`.
  - `load` — из «Максимальная нагрузка, кг».
  - `lighting` — только там, где подсветка встроена по тексту (СД-12: «лампы галогеновые» → `warm`). «Подсветка дополнительно» → `null`.
  - `price` — текущая цена на странице. Нет цены («Звоните») → `price: null`, `priceNote: 'по запросу'`.
- **Проекты**: короткий `title` и город — из подписи к фото. `summary` начинается с подписи сайта дословно. У дизайн-проектов добавлено «Оборудование изготовлено по дизайн-проекту сотрудников «ДВК Стиль»» — это подтверждает `/services/dizayn-proekt/dizayn-magazina/`. `client` и `year` — `null`.
- **Позиционирование** — формула из брифа (R13), на сайте её нет.
- **`facetLabels`** в `categories.json` — подписи значений фильтров «Материал» и «Подсветка».

## Фото

- Берутся только оригиналы `https://dvk-style.ru/upload/iblock/…` и `/upload/medialibrary/…`. Миниатюры `/upload/resize_cache/…` пересчитываются в адрес оригинала. Сжатые копии `dev2fun.imagecompress` не используются. Проверка — `isOriginalSource()` в `scripts/fetch-images.mjs`.
- Галереи проектов на сайте лежат в `/upload/medialibrary/`, не в `iblock`. Это тоже оригиналы, просто из другого хранилища Bitrix.
- На фото проектов есть водяной знак «ДВК Стиль» — так они выложены на сайте.
- Всего 148 фото, по два WebP на каждое, около 20 МБ:
  - 35 товаров — 86 фото;
  - 9 проектов — 21 фото;
  - 10 логотипов;
  - 11 серий аптек;
  - 20 сертификатов.
- Меньше 1600 px ничего не растягивается: файл `-1600` тогда равен оригиналу, реальные `w`/`h` записаны в JSON и манифесты.
- Манифест рядом с фото: `public/images/<…>/<slug>/manifest.json`. Общий свод: `public/images/manifest.json`. В записи — исходный URL, размер файла 1600 и размер оригинала.
